>
> Добавьте папку zapret в исключения антивируса либо выключите обнаружение PUA (потенциально нежелательных приложений). При уверенной настройке исключений лучше добавить исключение, но если вы не полностью понимаете последствия, рекомендуется отключить детектирование PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome найдите пункт "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query` (Cloudflare может быть заблокирован)
    * В Windows 11 Secure DNS можно включить непосредственно в настройках системы — [инструкция здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 это рекомендуемый вариант
    * Владельцам роутеров Keenetic нужно включить в настройках параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. На [странице последнего релиза](https://github.com/crushanbugap/zapret-discord-youtube/releases/latest) скачайте архив (zip/rar)

3. Откройте свойства загруженного архива и отметьте "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно не выполнять

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите подходящий файл
    * Найти работающую стратегию: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Добавить стратегию в автозапуск: **`service.bat`** -> `Install Service` -> *Выберите подходящую стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Ручной запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты (ALT, FAKE и прочие), пока не найдёте подходящий именно вам**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные действия:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск (services.msc)</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб
  - **`Check Status`** — посмотреть состояние обхода и служб (автозапуска стратегии и WinDivert)
  - **`Game Filter`** — изменить режим обхода для игр и прочих сервисов, использующих UDP и TCP на портах выше 1023.  
  **После смены режима стратегию необходимо перезапустить.**  
  В скобках отображается её текущий статус (включено/выключено).
  - **`IPSet Filter`** — изменить режим обхода ресурсов из `ipset-all.txt`.  
  Это удобно при проверке ресурса, который без zapret работает некорректно  
  В скобках показан текущий режим:
    - `none` — ни один IP не проходит проверку
    - `loaded` — IP сверяется со списком
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включить или выключить автоматический поиск обновлений
  - **`Replace active fakes`** — заменить используемый фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и соединения с голосовым чатом Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — найти распространённые причины неисправности zapret.  
  В конце можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; иногда это возвращает неожиданно переставший работать клиент
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — проверить сайты из `utils/targets.txt`
    - `DPI checkers` — протестировать DPI у разных провайдеров (Cloudflare, Amazon и других)


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться winws.exe (обход), видимый на панели задач.  
Если программа не появилась, обратитесь к [#522](https://github.com/crushanbugap/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит заменить его вручную:  
  - Выделите и скопируйте весь текст из открытого блокнота
  - В появившейся папке откройте `hosts` текстовым редактором, запущенным от имени администратора
  - Вставьте скопированное в конец `hosts` (либо замените аналогичный ранее добавленный фрагмент)
  - Сохраните файл и снова проверьте соединение. Если результата нет, убедитесь, что `hosts` действительно сохранился.

#### Работа не гарантируется. При отсутствии результата используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/crushanbugap/tg-ws-proxy) или любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Со временем стратегии могут перестать давать результат.**
> Стратегия способна работать некоторое время, а затем перестать из-за её обнаружения.
> В репозитории собрано много вариантов обхода. Если ни один не подходит, создайте новый на основе имеющегося и измените его параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` -> `Run Diagnostics` не показывает ошибок

- Проверьте наличие адреса ресурса в доменных списках или среди IP

- Переключитесь на другие стратегии (**`ALT`**/**`FAKE`** и другие)

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/crushanbugap/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- `service.bat` -> `Remove Services`
- `service.bat` -> `Run Diagnostics` (исправьте найденные ошибки) -> в конце Y
- Удалите каталог zapret
- Скачайте свежую версию [со страницы релизов](https://github.com/crushanbugap/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Щёлкните по архиву ПКМ и откройте свойства. Если внизу справа есть "Разблокировать", отметьте его -> примените изменения -> нажмите ОК
- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов
- Запускайте разные скрипты `general` и проверяйте интернет-ресурсы. Если доступ не появился, закройте программу (значок замка находится на панели задач) и попробуйте следующую стратегию
- После выбора рабочего варианта добавьте его в автозапуск: `service.bat` -> `Install Service` -> выберите нужную стратегию

### Не работает игра/приложение с включённым запретом

- Проверьте в service.bat, что `Game Filter` имеет статус **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит ругается на WinDivert

- Инструкция доступна здесь: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Получите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Выключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если прежняя стратегия больше не помогает, переберите остальные.
- См. также [#251](https://github.com/crushanbugap/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) включён
- Сначала желательно определить стратегию, на которой открывается сайт YouTube, и запустить её.
- В `service.bat` выберите `Run Diagnostics` и очистите там кэш Discord.
- Проверьте приложение Discord и выясните, помогла ли очистка кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ею.
- Если браузер тоже не подключается, снова проверьте все стратегии. YouTube и Discord могут работать на разных стратегиях.
- См. также [#252](https://github.com/crushanbugap/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/crushanbugap/tg-ws-proxy)
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Обычно помогает такой порядок действий:
- через `service.bat` обновите ipset и активируйте `Game Filter`
- если это не сработало, дополнительно включите `ipset any`

Однако режим `ipset any` способен нарушить открытие многих сайтов. Не оставляйте его включённым постоянно: определите IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`

Если результата нет, создайте обсуждение в разделе [Discussions](https://github.com/crushanbugap/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [здесь](https://github.com/crushanbugap/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Добавлять адреса для обхода можно в следующие файлы:
- **`list-general-user.txt`** — домены (поддомены учитываются автоматически)
- **`list-exclude-user.txt`** — домены-исключения, например когда IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
